The temporal query/export API requires bounded artifact selectors, a UTC cutoff,
an explicit operation and mode, and a narrow permission that names both allowed
operations and artifact kinds. Forward queries use actual receipt/observation
times. Reconstructed replay requires explicit permission and separate simulated
availability fields; original creation, observation, ingestion, and knowledge
timestamps remain intact in exports.

For learning exports and derived artifacts, the authority recursively validates
the full dependency closure against the applicable training, decision, memory,
index, and exchange-session cutoffs. Missing dependencies, cycles, unavailable
or late evidence, incomplete learned-artifact manifests, and stale index
membership fail closed. Cache identity includes the catalog fingerprint,
cutoffs, selectors, operation, mode, and permissions.

The storage boundary has code and migration-source evidence, not a live database
certification. `TemporalPermission` is required by the only implemented
query/export entry points. The migration guard test prevents direct outcome
table `SELECT` grants to `qc2_runtime_apexlab` or `PUBLIC`; static review found
schema `USAGE` only for the ApexLab runtime role and no outcome/research tables
or temporal SQL reader in the checked-in migrations. No QC2 database state or
production adapter was queried. This receipt does not claim production
deployment or live database enforcement.
