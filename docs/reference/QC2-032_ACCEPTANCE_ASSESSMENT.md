# QC2-032 — False Monster Review

## Acceptance assessment

- **Result:** PASS
- The research-only queue binds a frozen 12-decimal inclusive probability threshold to the exact label, score manifest, probability head and freeze time. It requires contemporaneous Prediction and ModelHeadOutput evidence, a resolved Outcome with valid endpoint, extrema, MFE and MAE fields, and a linked RunnerEvent and FailureGenome adjudication before creating a case. Existing FailureGenome taxonomy supplies the non-event, downside, timing-miss and data-error categories; data errors remain diagnostic rather than negative training labels. Missing probability/score evidence, unresolved outcomes, missing ground truth and missing adjudication stay in separate uncertainty records with available source references. Scientific success is excluded independent of paper execution or fill status. Proposed hypotheses are stored in a separate immutable hash-chained ledger and cannot mutate the canonical ReviewCase.
